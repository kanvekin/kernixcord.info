<Aside type="note">
    While the Flatpak is convenient, it comes with some limitations such as Rich Presence not working. We recommend using native packages for the best experience.
</Aside>

[![Download on Flathub](https://dl.flathub.org/assets/badges/flathub-badge-en.svg)](https://flathub.org/apps/org.kanvekin.kernixcord)

<IconHeader tag="h4" iconUrl={SteamIcon.src}>
    SteamOS
</IconHeader>

Open the Discover app, search for Kernixcord and install it. To run it in game mode, add it as a non-steam game.

<IconHeader tag="h4" iconUrl={UbuntuIcon.src}>
    deb (Debian / Ubuntu)
</IconHeader>

Download the right deb package and double click it to install.

<LinkButton href="https://github.com/kanvekin/kernixe/releases/latest" data-filename="kernixcord_VERSION_amd64.deb">x64 Download</LinkButton>
<LinkButton href="https://github.com/kanvekin/kernixe/releases/latest" data-filename="kernixcord_VERSION_arm64.deb">arm64 Download</LinkButton>

<IconHeader tag="h4" iconUrl={FedoraIcon.src}>
    rpm (Fedora / Red Hat)
</IconHeader>

Download the right rpm package and double click it to install.

<LinkButton href="https://github.com/kanvekin/kernixe/releases/latest" data-filename="kernixcord-VERSION.x86_64.rpm">x64 Download</LinkButton>
<LinkButton href="https://github.com/kanvekin/kernixe/releases/latest" data-filename="kernixcord-VERSION.aarch64.rpm">arm64 Download</LinkButton>

<IconHeader tag="h4" iconUrl={AppImageIcon.src}>
    tarball (Portable)
</IconHeader>

To run the portable version, extract it into a folder and run the `kernixcord` binary inside it. Note that all files are needed, not just the binary!
